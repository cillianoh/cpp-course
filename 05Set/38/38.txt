finder.cc must be compiled before main.cc. This is because in main.cc phoneBook is declared which itself delcares a static Finder member, s_finder. phoneBook.get() is then called in main.cc which uses s_finder to retrieve the phone number of a given person. As s_finder has only been declared and not defined yet it's data is not initated and a null pointer is returned causing no phone numbers to be outputted. This does not happen if finder.cc is compiled before main.cc as finder.cc defines and intialises s_finder. To fix this problem it would be best to define and intialise s_finder in main.ih instead of a seperate file so that compilation order does not change the programme.
