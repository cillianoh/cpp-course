  int x[8];           x[2] = x[3];

pointer notation:     *(x + 2) = *(x + 3);

semantics:  
   
This operation assigns the value of *(x + 3) to the value
stored in the pointer *(x + 2).

----------------------------------------------------------------------------
  char *argv[8];      cout << argv[2];

pointer notation:     cout << *(argv + 2);

semantics: 
   
The pointer will land on the address corresponding to 
base address + 2 * sizeof(char) and will print out the 
Third NTBS that is contained in the array. 

----------------------------------------------------------------------------
  int x[8];           &x[10] - &x[3];
		 
pointer notation:     &*(x + 10) - &*(x + 3) 

semantics:    

Although this is undefined behaviour according to the C++ standard, the compiler
Still performs pointer arithmetics, furthermore the pointer and the reference are 
inverse of each other, so the address operator Cancels out the dereference operator 
and we are just left with x + 10 - x - 3, So the result is just 7.

  main's argv;        argv++[0];

pointer notation:     *(argv++);	

semantics:

Assuming the executable + first argument is = ./a.out trial:
Since it's postfix operator, then the actual following explanation applies to 
The use of argv after the line that contained argv++[0]; terminates. 
Here first increment is applied to argv which is a pointer to a pointer to char
So the increment shifts which pointer of chars argv points to, hence dereferencing
Will output the second string given in the prompt, hence "trial".

----------------------------------------------------------------------------
  main's argv;        argv[0]++;

pointer notation:     (*argv)++;

semantics:   
  
Assuming the executable + first argument is = ./a.out trial:
Since it's postfix operator, then the actual following explanation applies to 
The use of argv after the line that contained argv[0]++; terminates. 
then the pointer is dereferenced first so the variable on which
the increment operator acts is the first string in argv, hence
the string "./a.out", but argv is a pointer to chars, so 
incrementing it will shift the pointer from "." to "/" , so by sizeof(char) .

----------------------------------------------------------------------------
  main's argv;        ++argv[0];

pointer notation:     *argv + sizeof(char);

semantics:

Assuming the executable + first argument is = ./a.out trial:
Here the operation happens at assignement already, first, the pointer that points
To a pointer of chars is not altered, so our string is still "./a.out" , but now 
We shift the start of the pointer by sizeof(char) so the ending result is "/" in 
the NTBS "/a.out".

----------------------------------------------------------------------------
  main's argv;        ++argv[0][2];

pointer notation:     *(*argv + 2 * sizeof(char)) + 1;

semantics:

Assuming the executable + first argument is = ./a.out trial:
Here we first dereference the pointer so we are accessing a specific NTBS in the array,
More specifically the name of the program since it's argv[0] = "./a.out", then, we access the 
Third character in argv[0], which is represented by argv[0][2] and hence corresponds to the 
character "a" in the string. After all of this is done, we increase the value of a, but since
it's a char, ++a will return the ASCII value right after the a one, which is b, hence the 
Whole sequence will output the character b.
